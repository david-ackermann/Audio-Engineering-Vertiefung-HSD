# Audioexports

Hier sollen Hoerbeispiele fuer die neu organisierte Vorlesung 7 liegen.

Sinnvolle Reihenfolge:

- `dry_sweep.wav`
- `iir_plus_05_impulse.wav`
- `iir_minus_05_impulse.wav`
- `allpole_resonator_impulse.wav`
- `feedforward_difference_highpass.wav`
- `biquad_lowpass_sweep.wav`
- `biquad_highpass_sweep.wav`
- `biquad_bandpass_sweep.wav`
- `biquad_notch_sweep.wav`
- `biquad_lowshelf_sweep.wav`
- `biquad_highshelf_sweep.wav`
- `biquad_peaking_sweep.wav`

Didaktischer Zweck:

- erst reines IIR hoerbar machen,
- dann zeigen, dass reine Rueckfuehrung nicht alle relevanten Kurven erzeugt,
- danach Feedforward-Ausloeschung hoerbar machen,
- am Ende die Biquad-Kurven als Ausblick auf die Anwendung vorbereiten.

Die Dateien werden erst erzeugt, wenn die passenden Exportskripte stehen.
