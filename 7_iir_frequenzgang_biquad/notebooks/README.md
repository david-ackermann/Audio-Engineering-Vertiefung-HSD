# Notebooks

Hier kann spaeter ein interaktives Notebook zur neu organisierten Vorlesung 7 liegen.

Moeglicher Name:

- `iir_biquad_playground.ipynb`

Sinnvolle Funktionen:

- reines IIR im Zeitbereich untersuchen,
- Feedback-Faktor `p` veraendern,
- mehrere Feedback-Taps vergleichen,
- Feedforward-Taps fuer Ausloeschung ein- und ausschalten,
- typische Filtertypen vergleichen,
- Frequenzgang und Impulsantwort parallel anzeigen,
- Biquad-Parameter hoer- und sichtbar vergleichen.

Biquads bilden den praktischen Abschluss von Vorlesung 7. Die z-Ebene folgt im
separaten Vorlesung-8-Ordner.
