# Audiosamples

Dieser Ordner sammelt Audiodateien, die in den kommenden Vorlesungen als wiederkehrendes Demo-Material verwendet werden.

## Grundidee

Die Beispiele sollen stark an `DAFX - Digital Audio Effects` von Zölzer anschließen:

1. Effekt zuerst hören.
2. Wahrnehmung mit DAFX-Kürzeln beschreiben: `L` Lautheit, `D` Dauer/Rhythmus, `P` Tonhöhe/Harmonie, `T` Klangfarbe/Qualität, `S` räumliche Eigenschaften.
3. Danach die technische Struktur erklären: Filter, Delay, Faltung, Modulation, Dynamik, Nichtlinearität oder STFT-Verarbeitung.

Die Originale liegen möglichst trocken und nachhallfrei vor. Bearbeitete Versionen können später pro Vorlesung oder Effekt zusätzlich exportiert werden.

## Ordner

- `nachhallfrei/`: trockene Ausgangssignale ohne hörbaren Raumanteil
