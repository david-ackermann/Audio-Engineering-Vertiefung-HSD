# Block 3: z-Ebene und Zeiger z

Diese Bildserie fuehrt die z-Ebene zuerst nur auf dem Einheitskreis ein.
Der freie Radius wird hier noch nicht behandelt.

- `01_z_plane_unit_circle.png`: z-Ebene mit Realachse, Imaginaerachse und Einheitskreis
- `02_z_vector_r1_omega.png`: Zeiger \(z=e^{j\Omega}\) auf dem Einheitskreis mit Pfeilbogen fuer \(\Omega\)
- `03_inverse_vector_z_minus_1.png`: der vorherige Zeiger grau, der Kehrwert \(z^{-1}=e^{-j\Omega}\) gruen

Der gruene Kehrwert-Zeiger ist der Systemanteil, der beim Ein-Sample-Delay
als Phasenfaktor wirkt.
