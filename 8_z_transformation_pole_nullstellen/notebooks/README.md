# Notebooks

Hier koennen spaeter interaktive Notebooks fuer Vorlesung 8 liegen.

Sinnvolle Notebook-Idee:

- `z_plane_poles_zeros_playground.ipynb`

Moegliche Funktionen:

- Punkte auf dem Einheitskreis bewegen,
- \(H(z)\) und \(H(e^{j\Omega})\) parallel anzeigen,
- Pole und Nullstellen interaktiv verschieben,
- Stabilitaetsgrenze visualisieren,
- Biquad-Koeffizienten und z-Ebene gemeinsam untersuchen.
